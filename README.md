# LPBF SDSS 2507 Hardness and Tensile Results

This repository contains hardness and tensile-test results, analysis notebooks, scripts, and figures for laser powder bed fusion (LPBF)-fabricated super duplex stainless steel 2507.

## Scope

The repository supports mechanical-property analysis of LPBF-fabricated SDSS 2507, including hardness measurements and tensile-test results across the investigated processing or post-processing conditions.

## Repository structure

```text
LPBF_AISI-2507-Hardness-and-Tensile-results/
├── README.md
├── LICENSE
├── figures/      # Plots and exported figures
├── hardness/     # Hardness data and analysis files
└── tensile/      # Tensile data and analysis files
```

## Contents

- Hardness datasets and analysis outputs
- Tensile-test datasets and analysis outputs
- Jupyter notebooks and/or Python scripts used for data processing
- Publication-ready figures

## Notes

- Mechanical-property values should be interpreted together with the processing condition, phase balance, porosity/defect state, and post-processing history.
- Raw or unpublished data should only be uploaded if public release is intended.
- Verify units, specimen geometry, and strain/stress conventions before reusing the data or scripts.
